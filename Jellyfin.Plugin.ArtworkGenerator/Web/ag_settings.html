Settings

Artwork Generator is turned on per library, under Image Fetchers in that library's settings. Profiles decide which images it makes.
Choices offered per image type in Edit Images. Each is a different frame, so a higher number is slower to open.
How long the choices rendered for Edit Images stay available, 5 to 1440. Until then, reopening the dialog or switching image type shows the same choices instead of rendering new ones.
Any whole number makes frame choice repeatable, so an item always gets the same frames. Empty picks new ones each refresh.
How frames are taken from a video and cleaned up, for every poster and every backdrop.
The bundled fonts are always available, and uploaded .ttf and .otf fonts join them in every font list.
