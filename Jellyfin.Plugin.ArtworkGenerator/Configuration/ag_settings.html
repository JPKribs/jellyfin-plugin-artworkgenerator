Settings

Generate the images your profiles turn on: automatically during a metadata refresh when an item is missing one, and on demand from an item's Edit Images dialog. Turning this off disables both. For series and seasons, also tick Artwork Generator under Image Fetchers for those item types in each library's settings.
How many alternates to offer per image type in an item's Edit Images dialog, 1 to 10. Each one is rendered from a different frame, so higher values make the dialog slower to open. Default is 3.
Leave empty to pick new frames on every refresh. Enter any whole number to make frame choice repeatable: the same item then always gets the same frames, which helps when comparing designs or reporting a problem.
